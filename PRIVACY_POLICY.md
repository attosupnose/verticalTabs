# Privacy Policy for "Vertical Tabs: compact, float" / "Вертикальные вкладки: компактные, растяжимые"

Last updated: 2026-02-20

## Summary

This extension does not collect, sell, or share personal data for advertising.

## What the extension accesses

The extension may access:

- Open tabs metadata (title, URL, favicon, tab/group state)
- Tab groups metadata
- User settings stored locally via Chrome storage

This access is used only to provide tab management features inside the extension UI.

## Data storage

- Settings are stored in `chrome.storage.sync` (for example: panel layout, language, UI preferences).
- No account system is used.
- No external database is used by the extension.

## Network requests

To improve favicon display for some websites, the extension may request favicon images from:

- `https://www.google.com/s2/favicons`
- `https://icons.duckduckgo.com/ip3/`

The extension avoids direct favicon probing for local/private network hosts.

## Data sharing

- No browsing data is sold.
- No personal data is shared with third parties for marketing.
- No analytics SDK is bundled.

## User control

You can remove all extension data by:

1. Uninstalling the extension, or
2. Clearing extension storage in Chrome extension settings.

## Contact

If needed, publish a support email or repository URL in your Chrome Web Store listing and reference it here.
